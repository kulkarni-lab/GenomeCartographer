# Derived acarine evolution involved coordinated erosion of ancestral genomic architecture
This repository contains the resources used to assemble the genome of Opilioacarida and analyze the genomes of Opilioacarida, Ixodida and Mesostigmata. If you use this repository, please cite as follows:

Salunkhe Shreya, Cherukutty Arjun, Khopkar Pratik, Mazumder Dibyo, Kulkarni Siddharth (2026). Derived acarine evolution involved coordinated erosion of ancestral genomic architecture.

The whole genome assembly was built with long reads from Oxford Nanopore Technologies.

## Folders in repository:
[Mir Machine](./Mir_Machine): Script and data files (FASTA, Annotation and Heatmap) for miRNA across genomes
