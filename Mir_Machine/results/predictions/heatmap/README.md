# miRNA copy number and conservation heatmap

This script helps in visualization for comparing microRNA (miRNA) family copy numbers and conservation patterns across species (here we have used Acari), using the output generated by MIRMachine. The script reads `.heatmap.csv` files generated by `MIRMachine`, combines miRNA family copy-number information across species, optionally applies a user-defined taxonomic order, and generates two heatmaps: `miRNA copy-number heatmap` `miRNA family presence/absence conservation heatmap`.

The figures are exported as `PDF`, `SVG` and `PNG` format.

## Requirements

Python 3.8 or newer.

Required Python packages;
`pandas` 
`matplotlib`
Python standard libray: `glob` `functools.reduce`

To install;
```
pip install pandas matplotlib
```


## Usage
The script can be simply run as;
```
python3 1.plot-heatmaps.py
```

One can give an optional taxon order file - `taxon_order.txt`. The taxon order file should contain ONE species per line.

Example: [`taxon_order.txt`](./taxon_order.txt)
```
Species1
Species2
Species3
Species4
```

[!NOTE] Make sure you are inside the directory containing output `.heatmap.csv` files from `MIRMachine`. 


# Input files

### 1. - The script expects `MIRMachine` output files ending in: `.heatmap.csv`

For example: 
```
Opilioacarus.heatmap.csv
Ixod.heatmap.csv
Galendromus.heatmap.csv
Phytos.heatmap.csv
Derma.heatmap.csv
```
- All `.heatmap.csv` files in the current directory are automatically detected using: `glob.glob("*.heatmap.csv")`

The `.heatmap.csv` contains 3 columns: `species` `family` `filtered_hits` 

Example `.heatmap.csv`
```
species,family,filtered_hits
Opilioacarus,miR-1,2
Opilioacarus,miR-2,1
Opilioacarus,miR-3,0
Opilioacarus,miR-4,5
```

The script reads species name using: species = `df["species].iloc[0]`. Therefore, the `species` column should contain the species identifier used for that particular `MIRMachine` result.
